# 2D Retro Black Hole Simulator in C

## What's this?
This is a 2D retro black hole simulator. This project is in C and uses raylib for graphics.
This project simulates a theoretical, non-spinning, Schwarzschild black hole.
Multiple light rays are shot at the black hole and you can see them curve around the black hole or go into the black hole
in a really beautiful way.

## Installation guide
To compile and run this project, you need to have [xmake](https://xmake.io/) on your system.

First you need to clone this repo
```bash
git clone [https://github.com/tahaqaisar/BlackHoleSimulator](https://github.com/tahaqaisar/BlackHoleSimulator)
```
Then you can compile it using xmake
```bash
xmake
```
To run this simulation
```bash
xmake run
```
