# A Simple Retro Black Hole Simulator in C

## What's this?
This is a simple retro black hole simulator. This project is in C and uses raylib for graphics.
This project simulates a theoretical, non-spinning, Schwarzschild black hole.
Multiple light rays are shot at the black hole and you can see them curve around the black hole or go into the black hole
in a really beautiful way.
